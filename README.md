# Gemini Canvas Markdown Copier

Google Gemini の「Canvas」機能で作成されたコードやテキストファイルを、ワンクリックで Markdown 形式としてクリップボードにコピーするための Chrome 拡張機能です。

## 特徴

- ワンクリックコピー: Canvas のツールバーに「📋 Copy」ボタンを追加します。これを押すだけでコピーできます。
- 自動 Markdown 整形: 
  - Markdownプレビュー画面の場合、HTML構造からMarkdown記法（見出し、リスト、コードブロック等）を復元します。
  - コード画面の場合、自動で言語を推測し、コードブロック（ \`\`\`lang ... \`\`\` ）で囲ってコピーします。
- 正確なファイル名取得: 画面上のファイル名を自動で検出し、コードブロックの言語指定に利用します。DOM構造探索と座標探索のハイブリッドロジックにより、高い精度を実現しています。

- ノンブレイクスペース対応: コンテンツ内のノンブレイクスペース（ `\u00A0` ）は、扱いやすい通常の半角スペースに自動変換されます。
- 確実なデータ取得: Gemini の「共有」メニューを経由して正規のコピー機能を利用するため、画面外のコードも欠けずにすべて取得できます。
## インストール方法

この拡張機能は Chrome ウェブストアには公開されていないため、「デベロッパーモード」を使ってインストールします。

### 1. ファイルの準備

任意の場所にフォルダ（例:  `gemini-downloader` ）を作成し、以下の3つのファイルを保存してください。

- `manifest.json`
- `content.js`  (v52.2 以降)
- `background.js`  (v14.0)
### 2. Chrome に読み込む

- Google Chrome を開き、アドレスバーに  `chrome://extensions/`  と入力して Enter キーを押します。
- 画面右上にある 「デベロッパーモード」 のスイッチを オン にします。
- 左上に表示される 「パッケージ化されていない拡張機能を読み込む」 ボタンをクリックします。
- 先ほど作成したフォルダ（ `gemini-downloader` ）を選択します。これでインストールは完了です。

## 使い方

- Google Gemini で、Canvas（コードやドキュメントのプレビュー画面）を開きます。
- Canvas 上部のツールバー（ファイル名や「閉じる」ボタンがある列）を確認してください。
- 青色の 「💾 DL」 ボタンが追加されています。
- ボタンをクリックします。

- 自動的にメニューが開き、データをコピーします。
- ボタンが「🤖」（処理中）→「✅」（完了）と変化すれば成功です。
- クリップボードに Markdown 形式のテキストが保存されます。

## ⚠️ 注意事項

- Google非公式: 個人が作成したスクリプトです。Google公式とは一切関係ありません。
- 仕様変更の可能性: Gemini側のアップデートにより、突然動かなくなる可能性があります。
- クリップボードへのアクセス: 拡張機能がクリップボードの読み取り・書き込み権限を使用します。
## 技術的な仕組み

この拡張機能は、以下の手順で動作します。

- 注入 (Injection): ページ読み込み時に、Canvas のツールバー構造を検出し、コピーボタンを埋め込みます。
- ファイル名特定: ボタンの親要素構造、またはボタンの物理的近傍にあるタイトル要素を探します。
- データ抽出:
  - Markdown: プレビュー画面のHTMLを解析し、Markdownテキストを再構築します。
  - コード: 共有メニューのコピー機能を利用してクリップボード経由で取得し、必要に応じてコードブロックで囲みます。
- コピー: クリップボードに最終的な Markdown テキストを書き込みます。
