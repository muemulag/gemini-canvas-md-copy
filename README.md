# Gemini Canvas Downloader

Google Gemini の「Canvas」機能で作成されたコードやテキストファイルを、ワンクリックでローカルにダウンロード・保存するための Chrome 拡張機能です。

## 特徴

- ワンクリック保存: Canvas のツールバーに「💾 DL」ボタンを追加します。これを押すだけで保存できます。
- 正確なファイル名取得: 画面上のファイル名を自動で検出し、適切な拡張子（.js, .py, .html, .md など）を自動で補完します。DOM構造探索と座標探索のハイブリッドロジックにより、高い精度を実現しています。
- Markdown整形: Markdownプレビュー画面の場合、HTML構造からMarkdown記法（見出し、リスト、コードブロック等）を復元して保存します。

- ノンブレイクスペース対応: コンテンツ内のノンブレイクスペース（ `\u00A0` ）は、扱いやすい通常の半角スペースに自動変換されます。
- 確実なデータ取得: Gemini の「共有」メニューを経由して正規のコピー機能を利用するため、画面外のコードも欠けずにすべて取得できます。
- 完全上書き保存: 常に指定したファイル名で保存し、同名ファイルがある場合は自動的に上書きします。
## インストール方法

この拡張機能は Chrome ウェブストアには公開されていないため、「デベロッパーモード」を使ってインストールします。

### 1. ファイルの準備

任意の場所にフォルダ（例:  `gemini-downloader` ）を作成し、以下の3つのファイルを保存してください。

- `manifest.json`
- `content.js`  (v52.2 以降)
- `background.js`  (v14.0)
### 2. Chrome に読み込む

- Google Chrome を開き、アドレスバーに  `chrome://extensions/`  と入力して Enter キーを押します。
- 画面右上にある 「デベロッパーモード」 のスイッチを オン にします。
- 左上に表示される 「パッケージ化されていない拡張機能を読み込む」 ボタンをクリックします。
- 先ほど作成したフォルダ（ `gemini-downloader` ）を選択します。これでインストールは完了です。

## 使い方

- Google Gemini で、Canvas（コードやドキュメントのプレビュー画面）を開きます。
- Canvas 上部のツールバー（ファイル名や「閉じる」ボタンがある列）を確認してください。
- 青色の 「💾 DL」 ボタンが追加されています。
- ボタンをクリックします。

- 自動的にメニューが開き、データをコピーして保存します。
- ボタンが「🤖」（処理中）→「✅」（完了）と変化すれば成功です。
### 💡 ヒント: 正確なファイル名で保存するために（推奨）

Canvasのタイトルが「無題」や日本語のタイトルの場合、拡張機能が内容から推測してファイル名を付けますが、意図しない名前になることがあります。
最も確実な方法は、Canvasのタイトル自体を「拡張子付きの物理ファイル名」にしておくことです。

Geminiにコード生成を依頼する際、プロンプトに以下の命令を添えることをお勧めします。

「Canvasのタイトル（管理名）は、 `script.js`  や  `index.html`  のような拡張子付きの物理ファイル名にしてください。」
## ⚠️ 重要な注意事項：上書き保存について

本拡張機能は、効率的な作業のために**「同名のファイルが存在する場合、警告なしで上書き保存する」**仕様になっています。

- ダウンロードフォルダ内に同じ名前のファイルがある場合、新しい内容で即座に上書きされます。
- 過去のバージョンを残したい場合は、Git等でバージョン管理を行うか、Canvas上でファイル名を変更してからダウンロードしてください。
## 技術的な仕組み

この拡張機能は、以下の手順で動作します。

- 注入 (Injection): ページ読み込み時に、Canvas のツールバー構造を検出し、DLボタンを埋め込みます。
- ファイル名特定: ボタンの親要素構造、またはボタンの物理的近傍にあるタイトル要素を探します。
- データ抽出:

- Markdown: プレビュー画面のHTMLを解析し、Markdownテキストを再構築します。
- コード: 共有メニューのコピー機能を利用してクリップボード経由で取得します。
- 保存:  `background.js`  にデータを送信し、ChromeのダウンロードAPIを使って上書き保存します。
